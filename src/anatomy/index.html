开源解剖

这一栏要回答的不是「多少星、哪天创建」，而是：它到底在搬动什么状态，核心算法闭环是什么，和常见替代方案差在哪，以及在什么边界上会失效。

每篇文章都是零外部依赖的单页（样式内联，脚本在同目录 anatomy.js），可点击架构图和阶段卡片。结论按「源码确认 / 作者宣称 / 推断 / 待验证」标注，并给出分析时的版本、提交与永久链接。分析由助手根据公开源码整理，可能有误，以仓库原文为准。

以后怎么加新文章

生成器每次刷新会清空「不是这次产出的文件」。解剖页必须放在源目录里，由生成器原样复制，而不是直接只丢在站点根上。

  1. 在 src/anatomy/ 新增独立 HTML（可复制现有文章骨架），同目录已有 anatomy.js，不要引入外部 CDN 或统计脚本。
  2. 在本索引页加上一张卡片：链接、标签（data-tags）和检索词（data-hay）。
  3. 重新运行 python3 generate.py <输出目录>。生成器会把 src/anatomy/ 下的 .html / .js / .css / .json / .svg / .txt 复制到输出目录的 anatomy/，并登记到产出清单，避免被清理步骤删掉。
  4. 顶栏「解剖」由生成器写入全站导航；不必再手改各栏目页。文章本身请写明版本、提交、北京时间与证据分级。
