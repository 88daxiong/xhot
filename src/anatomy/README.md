# 开源解剖（源文件）

这一目录是 XHOT「开源解剖」栏目的源文件。`generate.py` 会把其中的 `.html` / `.js` / `.css` / `.json` / `.svg` / `.txt` 原样复制到输出站点的 `anatomy/`，并登记到产出清单，避免清理步骤删除。

本目录的 `README.md` 不会被复制到站点。

## 新增一篇文章

1. 复制现有 `git-twig.html` 或 `motlab.html` 的骨架，在本目录新增独立 HTML。使用同目录已有的 `anatomy.js`，不要引入外部 CDN、字体或统计脚本。
2. 在 `index.html` 增加一张卡片，填写 `href`、`data-tags` 和 `data-hay`。
3. 文中写明分析所用版本、提交哈希、北京时间，并区分「源码确认 / 作者宣称 / 推断 / 待验证」。
4. 运行 `python3 generate.py <输出目录>`。全站顶栏「解剖」已由生成器写入，不必手改各栏目页。

页面应沿用 XHOT 的顶栏、字号和移动布局，并在浅色 / 深色主题下可读。
