开源解剖

先看这个项目最特别的一点，再用一张流程图看懂它怎么运转，然后决定它适不适合你。细节留在各篇后面。

下面十篇都会直接显示。搜索和筛选只是辅助，不是入口。

个人助手TypeScriptnod-v0.9.7

Nod

最大亮点：政策在服务器里执行，不在提示词里商量；工具结果标成不可信数据，对外动作先写成待批准快照。

适合：希望在自己的电脑上跑一个会处理邮件和网页差事的个人 Agent，并且在对外行动前先问你。

Agent 记忆Rustv3.4.7

ai-memory

最大亮点：多个编程 Agent 共享一份可 grep 的 Markdown 记忆，默认不必调用大模型。

适合：你同时用 Claude Code、Codex 等工具，希望换工具或换电脑时还能接上「上次做到哪」。

阅读拆解 →
文档 RAGGov0.9.0

WeKnora

最大亮点：企业文档问答在生成前会登记可核对的引用，并且先按租户授权再检索。

适合：要把制度、手册、资料库做成带出处的问答，或把知识库接到 Agent / IM 渠道。

阅读拆解 →
Git / 存储Rustv0.4.0

git-twig

最大亮点：文件系统支持克隆时，用写时复制做 Agent 工作树，并在字节对不上时退回普通 git worktree。

适合：多个 Agent 要并行检出同一仓库，并关心磁盘占用。

视频渲染JavaScriptv0.2.2

motlab

最大亮点：把每一场戏写成会按时间画画的网页，在无头 Chrome 里用 WebCodecs 编码，再在本机拼接成片。

适合：想用代码精确控制短视频画面，而不是让模型直接生成整段成片。

规则聊天Pythonv0.1.0

PyBot

最大亮点：没有权重的规则聊天机器人——固定运行时做观察、提议和仲裁，智能体群写出大量可检查的规则模块。

适合：想看清规则机器人如何选题和记会话，或研究用智能体群生成可运行代码，而不是拿它当通用助手。

阅读拆解 →
Rust 迁移Rustv1.1.0

rust-anything

最大亮点：不翻译代码，而是给编码代理一条可判定闭环：录下原实现行为，生成桥接，对拍通过才算完成。

适合：要把 TypeScript、Python、C、Go、Ruby 或 Java 的热路径逐步换成 Rust，并且每一步都能证明结果没变。

阅读拆解 →
Agent 运行时Rustv1.0.0

borg

最大亮点：把多次 LLM 调用编成可取消、可隔离恐慌、有预算、崩溃后按组合树指纹恢复的流水线。

适合：在 Rust 里编排模型调用，并且必须把取消、并发上限和检查点写成硬约束，而不是散落在业务代码中。

阅读拆解 →
多智能体JavaScriptv0.3.0

MAS Office

最大亮点：每个角色都是本机真实的 Claude Code 或 Codex 会话；先锁定团队设计，工具调用只经过一个执法点，面板是事件日志的投影。

适合：要把调研或决策任务分成多个已登录的编码代理角色，并在同一个收件箱里处理批准和检查点。

聊天接入TypeScriptv0.3.1

Mingle

最大亮点：一个长期存在的本机 Agent，以官方机器人身份出现在你正在用的聊天软件里；所有消息进入同一条可恢复的编码代理会话。

适合：已经在用 Claude Code 或 Codex，希望同一个 Agent 出现在飞书、Slack、Telegram 等对话里，并且不把聊天记录交给第三方服务器。

ai-memory 和 WeKnora 不是同一层的东西

它们都和「Agent + 知识」有关，但不宜当直接竞品：一个记住编码过程中的工作记忆，一个把组织文档做成可引用的知识库。也可以一起用。
