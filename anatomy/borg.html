borg

把多次 LLM 调用编成可取消、可隔离恐慌、可重试、有预算、崩溃后能接着跑的流水线。它是库，不是带供应商客户端的产品。

最大亮点

把「编排 LLM 调用」从业务代码里抽成监督运行时：组合子描述怎么跑，执行器在每个边界检查取消与预算，子任务恐慌不会带走兄弟任务，流水线形状变了就不能拿旧检查点接着跑。

常见写法是自己 tokio::spawn 再拼重试。一旦要取消整棵树、限制并行打到供应商的请求、或在崩溃后跳过已完成步骤，这些约束容易散落各处。borg 的 Supervisor 给每个孩子单独的取消令牌和 JoinSet，并用 catch_unwind 把恐慌收成 ChildPanicked；execute_resumable 用组合树指纹拒绝形状不匹配的快照。源码确认

一句话输入输出：输入是一棵 Composition（智能体、工具、预算、取消令牌和可选检查点存储）；输出是 Verdict / ExecutionOutcome，以及按策略写下的快照。仓库不附带任何真实模型客户端，示例走内置 FakeLlmClient。

怎么用

什么情况下用

  • 你在写 Rust 服务，要把多次模型调用编成流水线，并且必须能取消、限制并发、崩溃后接着跑。
  • 需要把重试、熔断、模型降级和工具 / MCP 调度放在同一套组合子里，而不是散落在业务代码中。
  • 想先用 FakeLlmClient 把监督与检查点测通，再自己实现 AgentLlmClient 接真实 API。

什么情况下不用

  • 只想要开箱即用的 Claude Code / Codex 产品或带官方客户端的框架——borg 明确不附带供应商客户端。
  • 需要现成的虚拟机 / 容器隔离。默认的 borg-sandbox 后端是普通子进程，权限与调用者相同，文档写明它不是隔离层。
  • 不能接受从 Git 标签依赖、也不想自己实现 LLM 客户端。它不发布到 crates.io（该名已被无关 crate 占用）。

深入

下面这些不影响先建立整体图景。需要对照源码、字段或边界时再展开。证据仍指向固定提交 7030d45。

组合树与交接状态
  • Composition 包括 Single、Sequential、Parallel、LoopUntil、Branch、Fallback、FallbackLadder、Agent（工具循环）等。Parallel 在扇出时给各支路同一份交接快照，扇入时合并写入；构建器要求支路名（以及声明的 output_key）唯一。crates/borg/src/composition.rs:303–340 源码确认
  • LoopUntil 的 body 是工厂，每次迭代用 LoopCtx 重建，从而不必让 Composition 实现 Clone。crates/borg/src/composition.rs:334–347
  • Agent 变体把「一次模型调用 + 该次响应里的全部工具调用」算作一步；结果写入交接槽 tool_results。crates/borg/src/composition.rs:370–390 行号随枚举变体位置，以链接为准。
监督：取消、恐慌隔离、并发上限
  • 模块文档写明：这不是完整 Actor 系统，没有消息传递或链接；重启策略是 OneForOne。crates/borg/src/supervisor.rs:1–23 源码确认
  • 父取消令牌派生 child_token()，取消会传到后代；信号量限制同时进行的 LLM 往返，避免宽 Parallel 打满供应商限额。丢弃 Supervisor 会中止仍在飞行的孩子。crates/borg/src/supervisor.rs:6–14 crates/borg/src/supervisor.rs:95–99
  • 合作式取消走孩子的 token；abort() 是后盾，会直接丢弃 Future。执行器在边界看见父取消时立即发出 Cancelled。crates/borg/src/supervisor.rs:47–58 crates/borg/src/executor.rs:16–18
  • 工作区 Cargo.toml 故意不设 panic = "abort"，因为监督依赖 catch_unwind。若你的二进制改成 abort，恐慌隔离会失效。源码确认
预算入场与缓存计价
  • Budget::admit_parallel(branches, min_per_branch) 在任何支路生成前做入场检查，结果可以是放行、降级或拒绝。crates/borg/src/budget.rs:83–140 源码确认
  • TokenUsage::chargeable 可把缓存读取按百分比计价（向下取整）。默认 InMemoryBudget 对缓存读取按 100% 计；注释说明若把 20K 缓存前缀当成 20K 全价，会吃空会话池。crates/borg/src/budget.rs:54–65 crates/borg/src/budget.rs:188–196
  • sub_budget 可从会话预算再切出一轮子预算。crates/borg/src/budget.rs:263–274
检查点：指纹必须对上
  • Snapshot 带 schema 版本和组合树指纹。恢复时执行器先比版本，再比指纹；对不上就返回 BorgError::Internal，避免用新树去读旧进度。要改结构得先 CheckpointStore::delete。crates/borg/src/checkpoint.rs:12–15 crates/borg/src/executor.rs:562–587 源码确认
  • 入口是 execute_resumable / execute_resumable_with。crates/borg/src/executor.rs:536–553
取舍、失效边界与替代方案
  • 与 LangGraph / 自写 Tokio 监督相比：borg 把取消传播、恐慌隔离、预算入场和检查点指纹放进核心库，但换来的是你必须实现 LLM 客户端，并且运行时是 Rust。推断
  • TokioBackend 明确「不是隔离」：以调用者权限跑普通子进程；要跑不信任代码，需自己实现 SandboxBackend。crates/borg-sandbox/src/lib.rs:1–16 源码确认
  • 失败分类把额度用尽、上下文超长等标成不可重试；重试靠字符串 / 状态码启发式，分类错了就会误重试或过早放弃。推断
  • 仓库声称另有护栏（Warn / Throttle / Halt）、滑窗熔断、重启风暴（meltdown）和 MCP 接入。实现文件存在（如 guardrails.rs、meltdown.rs、crates/borg-mcp），本文未逐步走完每条路径。待验证
