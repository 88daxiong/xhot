关于 XHOT

XHOT 是一个纯静态的个人项目：每天一次，把 X 上 AI / 搞钱 / 成长领域 132 个公开账号的热点整理成 10 分钟能读完的简报。没有登录、没有广告、没有统计脚本、没有第三方请求。

数据来源

  • X：通过 X 官方 API（只读，开发者账号授权）获取公开帖子与账号资料。站内展示的是短摘录、互动数字和指向原帖的链接；每条都可点「在 X 打开」查看完整原文。X 开发者协议与政策适用于这些内容。头像为小尺寸缓存，仅用于标识作者。
  • AIHOT：资讯页的精选与热点来自 aihot.news 的公开 API，按其 MIT 许可使用并署名；文章原文版权属于原站，本站只给链接。许可声明见仓库中的 LICENSE-THIRD-PARTY.md。
  • GitHub Trending：趋势页读取 GitHub Trending 公开页面中的项目名与星标数，只做索引并链接到项目主页，不转载项目内容；每日一次，不做高频抓取。 Agent 页另用 GitHub 公开搜索 API（不登录，每天约 20 次）补充近期新建项目与创建日期；项目一句话中文介绍由 AI 助手撰写，以项目主页为准。

哪些内容是 AI 生成的

  • 「今天一眼看完」「必读」中的中文要点、英文帖的中文译文（带「译」标记）、人物「本周要点」和话题解读，均由 AI 助手自动整理，不是 X 官方内容，也不代表原作者的表述，可能有误；以原帖为准。
  • 热度、重要度、标签是公开的规则公式 / 关键词规则计算的结果，不是 X 官方排名。

内容撤下与合规

  • 每天刷新一次；X 已删除、改为受保护或不再可获取的帖子，会在下一轮刷新后撤下。站点另有一份撤下清单，可按帖子或账号即时屏蔽。
  • 如果你是原作者或相关方，希望撤下某条内容、头像或整个账号，请在 GitHub Issues 留言（只需给出帖子或账号链接，不要提供个人隐私信息），我们会尽快处理。
  • 站内不收集访客信息：偏好（主题、密度、已读标记）只保存在你自己的浏览器里。
