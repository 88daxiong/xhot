Meta 发布 Muse Wonder 系列前沿模型

Meta 于 10 月 12 日发布 Muse Wonder 和 Muse Wonder Full 两款前沿智能体模型，这是其 Superintelligence Labs 成立一年多后的首批前沿模型。据 Artificial Analysis 实测，两款模型在 Intelligence Index v4.3 上分别得 52 和 56 分（最大推理量），较六周前 Muse Spark 1.3 的 48 分明显提升；Muse Wonder Full 在该指数上排名第二，距 Claude Opus 5.5 仅 2 分。

两款模型开放范围不同：Muse Wonder 可通过 Meta Model API 和 Muse Code 使用，定价为每百万 token 输入 4 美元、缓存输入 0.20 美元、输出 20 美元；Muse Wonder Full 仅面向 Muse Code 订阅用户，不在 API 提供，按 token 定价尚未公布。Meta 称 Muse Wonder 将陆续接入 Muse 等其他产品，先向订阅用户推送。

Meta 称该系列在个人与专业智能体、记忆和编码基准上达到 SOTA，配备跨对话保留上下文的 Active Memory 和遇阻持续尝试的 Active Focus，并称在抵御对抗性指令、处理隐私信息方面做了专门训练。第三方评测者则给出不同侧重：有开发者称 Muse Wonder 一次找出其他 Agent 遗漏的代码漏洞，也有人汇总称 Muse Wonder Full 在 14 项公开基准中 8 项超过 Opus 5.5。

Karpathy：LLM 能力认知鸿沟扩大为漏斗

Andrej Karpathy 重发并扩展其 4 月的观点，称外界对 LLM 能力的共识差距正从“两群人各说各话”变成一个急剧收窄的漏斗。他估算全球约 60 亿人（约 75%）几乎未接触过 LLM，约 10 亿至 20 亿人偶尔使用免费层类 ChatGPT 产品，约 2000 万人在数学与编码领域直接使用前沿模型，仅约 5000 人能接触前沿级内部系统。

Karpathy 称，漏斗由问题规模、系统能力的锯齿状分布和访问层级共同驱动，不同人群对同一批系统的感知因此差异极大。他称约 2000 万数学与代码专业者能看到智能体在数周内完成过去数月的项目，约 5000 名实验室内部人员则在观察数千智能体协作数周的软件大型项目、漏洞挖掘、网络攻防、科学发现与前沿数学进展。

Ethan Mollick 转引该推文并补充称，即使这 5000 名内部人员中许多也未充分发挥先进模型能力，其应用集中在网络安全、数学与 AI 研发，还有许多其他领域和问题可以推进。Oran Ge 则称，大部分人不用大模型是因为大模型对他们没用、没有 ROI。
