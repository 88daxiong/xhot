OpenAI 发布 GPT-6.2 Astra 与 Sol 两款模型

OpenAI 于 11 月 18 日发布 GPT-6.2 Astra 和 GPT-6.2 Sol，即日起向 ChatGPT Work 和 Codex 的 Plus、Pro、Enterprise 及 Edu 用户开放，开发者可在 API 中调用 gpt-6.2-astra 和 gpt-6.2-sol。官方称 Astra 是面向最难项目的旗舰模型，代码更干净、前端与 3D 能力提升；两款模型主打游戏制作，也用于制作幻灯片、搭建网站和处理日常任务。IT之家称，符合条件的 Enterprise 和 Edu 用户还需由工作区管理员启用，且两款模型暂未加入 ChatGPT 普通聊天模式。

OpenAI Developers 称，API 中 Astra 标准输入输出 token 价格比 GPT-6 Astra 低 20%，Sol 在与 GPT-6.1 Sol 相同的每 token 成本下能力更强；Astra 在 Agents' Last Exam 上比 GPT-6 Astra 高 5.2 分，单任务成本不到其三分之一。Ultrafast 方面，Pro 500 订阅者可用于任一模型，Pro 200 订阅者首次获得该功能、从 Sol 开始；未来三个月 Ultrafast 价格下调 50%，对 API 和 Enterprise 用户仅为 Standard 的 3 倍成本。MarkTechPost 称，Ultrafast 在 2027 年 2 月 28 日前为 Standard 的 3 倍，之后为 6 倍；超过 272K 输入 token 的请求输入与缓存费率翻倍、输出为 1.5 倍，Batch 为 Standard 的 50%。

OpenAI 称 Astra 是迄今网络攻防能力最强的模型，在 ExploitBench Internal Port 上比 GPT-6 Astra 高 22 分，因此两款模型对高风险网络安全协助设置了更严格防护，并正推动上线 Daybreak，让经批准的防御者以更少拒答使用。Artificial Analysis 称，Astra 在其 Intelligence Index 上涨 5 分至 62，两款模型在该指数中位列第二，并占据大部分 Cost per Task 帕累托前沿；该机构同时称编码代理能力没有提升。发布前，X 用户卡兹克称灰度体验中 Sol 审美“强到爆炸”、防御性问题改善，并发 20 个前端测试 10 分钟仅耗 200 美元 Pro 额度的 1%，这些属个人灰度体验。
