Anthropic 发布 Fable 5.2 与 Mythos 5.2，多项评测登顶

Anthropic 发布 Claude Fable 5.2 和 Claude Mythos 5.2，两者基于同一底层模型。Fable 5.2 面向所有付费计划开放，内置拦截高风险网络安全与生物研究任务的防护；Mythos 5.2 移除部分限制，仅向通过网络安全或生命科学验证计划申请的组织开放。Fable 5.2 定价为每百万输入 token 8 美元、输出 40 美元，较 Fable 5.1 的 10/50 美元降 20%，支持 100 万 token 上下文，并已在 Claude Code、OpenRouter、Cursor、Perplexity、Google Cloud 等平台上线。

评测方面，ARC Prize 公布 Fable 5.2 在 ARC-AGI-2 得 93.8%，为其见过的第三高，仅次于 GPT-6 Astra 的 95.0% 和 GPT-6.1 Sol 的 94.2%；ARC-AGI-3 在 provider adapter harness 下得 97.7%，标准 harness 下 xhigh 档得 81.2%。ARC Prize 称，标准 harness 下 max 档有 28/55 个半私有游戏触及 12 小时时限，得分 65.7%，若无时限预计更高；并指出已发布版本在 medium 和 xhigh 档的调优与其此前评估的检查点不同。Artificial Analysis 智能指数 v5 以 65 分登顶，Arena Code Arena: WebDev 以 1832 分居首，Remote Labor Index 以 41.3% 领跑。

Anthropic 称 Fable 5.2 解决了两个与黑洞相关的理论物理开放问题，包括一项 23 年未完成的计算。订阅权益上，Pro 用户获一次 Fable 重置，Max、Ultra 和 Team Premium 按订阅时长最多三次，可用至 3 月 8 日；Pro 和 Team Standard 另有一周试用期，额度不超过每周上限的一半。Addy Osmani 称该模型 token 消耗大，按单任务计成本与 Fable 5.1 大致相当。
