Meta 开源 816B 模型 Muse Spark Open，Apple 演示 Mac Studio 本地运行

Meta 发布开放权重模型 Muse Spark Open，总参数 816B、每 token 激活 42B，上下文窗口 1M token，原生支持文本、图像、音频、视频输入，主打编码与长程智能体任务。Meta 称其为迄今最强的美国开放权重模型，权重以 Muse Model License 在 Hugging Face 等平台开放下载，并同步上线 Baseten、Fireworks AI、Groq、Modal、Nebius、OpenRouter、Together AI 等 API 平台。Artificial Analysis 称该模型在其 Intelligence Index 得 39 分，为美国开放权重模型第一；Arena 后续公布其在 Code Arena: WebDev 以 1511 分居美国开源模型第一、开源模型总榜第 13。

Apple 机器学习研究团队演示用新版 MLX（v0.30.1 起）与 macOS 26.2 的 RDMA over Thunderbolt 驱动，在两台 Apple M5 Ultra Mac Studio 上本地运行该模型；Meta 称这是同类中首个可在桌面端以两台 Mac Studio 运行的模型，双方在发布上合作。

许可方面，The Decoder 报道该许可免费使用但要求标注“Built with Muse Spark Open”，年收入超过 2000 万美元、想以 API 服务提供该模型的供应商需与 Meta 另签协议。Meta 首席 AI 官汪滔称，出于安全与能力边界考量，Meta 通常不会开源最顶尖模型，但会继续发布优秀开源模型；该模型性能低于此前发布且保持闭源的 Muse Wonder。
