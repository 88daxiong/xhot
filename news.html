Claude artifacts 可安装为 Mac 和 Windows 桌面应用

Anthropic 在 Mac 和 Windows 版 Claude 桌面应用中推出 beta 版“Install as app”：用户让 Claude 构建一个 artifact 后点击安装，即可像普通应用一样打开，拥有自己的图标和窗口，底层 artifact 更新时应用自动同步。Claude Devs 称，用户无需打包或签名应用，也无需配置 API key；应用可使用用户的 connectors，经允许后还能发送通知或添加菜单栏项。

该功能在 Claude Desktop 所有计划上以 beta 形式开放，但 HIPAA-ready 组织和混合部署无法使用；Team 计划默认开启，但完整访问权限关闭；Enterprise 计划默认关闭，需管理员先开启。构建应用及其对 Claude 的调用计入用户的用量限制。The Decoder 称，使用该功能需要最新版 Claude 桌面应用，免费账户即可。

Anthropic 员工 Ado Kukic 转引 Felix Rieseberg 的说法称，无需编程技能即可用 Claude 构建并分享 Mac 和 Windows 应用。IT之家称，安装后的应用可授予完整计算机访问权限，并支持拦截快捷键、置顶显示等权限选项。Lydia Hallie 补充称，Artifacts 在付费计划下提供个人与共享存储，默认使用打开者的连接器。
