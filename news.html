Anthropic 发布 Fable 5.2 与 Mythos 5.2，多项评测登顶

Anthropic 发布 Claude Fable 5.2 和 Claude Mythos 5.2，两者基于同一底层模型。Fable 5.2 面向所有付费计划开放，内置拦截高风险网络安全与生物研究任务的防护；Mythos 5.2 移除部分限制，仅向通过网络安全或生命科学验证计划申请的组织开放。Fable 5.2 定价为每百万输入 token 8 美元、输出 40 美元，较 Fable 5.1 的 10/50 美元降 20%，支持 100 万 token 上下文，并已在 Claude Code、OpenRouter、Cursor、Perplexity、Google Cloud、OpenClaw 等平台上线。

评测方面，ARC Prize 公布 Fable 5.2 在 ARC-AGI-2 得 93.8%，为其见过的第三高，仅次于 GPT-6 Astra 的 95.0% 和 GPT-6.1 Sol 的 94.2%。Artificial Analysis 智能指数 v5 以 65 分登顶，Arena Code Arena: WebDev 以 1832 分居首，Remote Labor Index 以 41.3% 领跑；Arena 最新称 Fable 5.2 (Max) 以 +30.4% 净提升登顶 Agent Arena，约为第二名 Opus-5.5 的 1.6 倍，数据来自 4.7k 真实智能体会话。Anthropic 称 Fable 5.2 解决了两个与黑洞相关的理论物理开放问题，包括一项 23 年未完成的计算。

订阅权益上，Pro 用户获一次 Fable 重置，Max、Ultra 和 Team Premium 按订阅时长最多三次，可用至 3 月 8 日；Pro 和 Team Standard 另有一周试用期，额度不超过每周上限的一半。Addy Osmani 称该模型 token 消耗大，按单任务计成本与 Fable 5.1 大致相当。
