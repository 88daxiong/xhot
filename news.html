Anthropic 开放 Claude Duet 主动式智能体研究预览

Anthropic 以研究预览形式开放 Claude Duet，一款让 Claude 作为主动式智能体工作的独立应用，已登陆 iOS、Android 和 claude.ai。首批面向美国 Pro 和 Max 用户，需加入等候名单；预览阶段包含在 Pro 和 Max 套餐内，使用与 Claude 其余功能相同的用量额度。

据 Claude 官方账号，Duet 会主动提示需要关注的事项、完成用户交办的任务、在用户离开后继续工作，并在代替用户行动前先向用户确认。Testing Catalog 报道称，Duet 基于 Claude Opus 5.5 构建，记忆、技能和已连接应用继承自用户的 Claude 账户，并可使用 Stripe 的 Link 数字钱包进行企业采购、通过 Shopify 的 Shop Pay 在线结账，还将支持用 1Password 保存的登录信息登录网站。

The Verge 称 Duet 对标 Meta 的 Muse 和 OpenAI 的 Dots，面向专业人士和小企业主。Claude Code 产品负责人 Cat Wu 给出加入等候名单的地址 claude.com/product/claude-duet，称 Duet 会注意到需要完成的工作，在用户开口之前就去做。Anthropic 未说明正式上线时间。
