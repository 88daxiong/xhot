OpenAI 发布 GPT-6.1 Terra，API 价格减半

OpenAI 发布 GPT-6.1 Terra，定位为快速、低价的计算机操作与视觉推理模型，能理解屏幕内容、跨应用执行操作并自然写作。标准 API 定价为每百万 token 输入 1 美元、缓存输入 0.05 美元、输出 5 美元，是 GPT-5.6 Terra 的一半；Batch 和 Flex 价格再低 50%，Fast 模式为标准价的两倍。模型以 gpt-6.1-terra 提供，并在 ChatGPT Work 和 Codex 中向 Plus、Pro、Enterprise、Edu 用户开放。

OpenAI 员工 Vaibhav Srivastav 称，Terra 在 Agents' Last Exam 上比 5.6 Terra 提升 15 分，成本约为三分之一；OpenAI 的 Tibo 称，Terra 在 API 和订阅中提供的用量是 6.1 Sol 的 2 倍。TestingCatalog 引述官方说法称，Terra 在 max effort 下 token 效率是 Claude Opus 5.5 的三倍以上，每任务成本约低 9 倍。Greg Brockman 称，Terra 的电脑操作已跨过质变门槛，用起来比他不借助 AI 时更快。Srivastav 另引 Roboflow 视觉基准称，Terra 在文本、目标检测、计数等任务上胜过 Astra，速度约快 47%、成本约便宜 92%。

第三方方面，Artificial Analysis 称 Terra 是 GPT-5.6 之后首个 Terra 级模型，智能更高而成本不到三分之一；OpenRouter 已上线该模型，定价与官方一致，上下文 1.05M，并称其在 Agents' Last Exam 上与 GPT-6 Astra 得分相当、每 token 价格约为其十分之一。Arena 公布 GPT-6.1 Terra (Max) 在 Code Arena: WebDev 以 1671 分列第 14，比 GPT-5.6 Terra 高 151 分。OpenAI 系统卡增补称，Terra 沿用 GPT-6 Astra 的数据与训练方式，生物与化学能力定为 High，Multimodal Troubleshooting Virology 越过指示性阈值。
