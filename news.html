Google 发布 Gemini 4 Argon，仅付费用户可用

Google 正式发布旗舰模型 Gemini 4 Argon，即日起全球上线，定位为面向复杂编码、智能体、数学和科学任务的最强模型。该模型仅向付费用户开放：开发者与企业需使用 Gemini API 和 Gemini 平台的付费层级，Google Antigravity 中仅限 Ultra 订阅者，Gemini 应用和搜索 AI Mode 中仅限 Ultra 和 Pro 订阅者。The Decoder 称免费用户和 Plus 订阅者只能继续使用较弱的 Flash 系列模型。

定价方面，Google 公布上线初期价格为每百万输入 token 2 美元、每百万输出 token 10 美元，缓存输入享 95% 折扣；MarkTechPost 称 2026 年 11 月 30 日后价格将涨至输入 4 美元、输出 20 美元。模型支持 1M 统一输入输出 token 上限。Google 还表示，科学家和研究人员可申请免费使用 Antigravity 最高使用档位 6 个月，网络安全防御人员可通过 Fairwind Program 申请，均需符合资格、容量和筛选条件。

Google 声称 Argon 在编码、网络安全、科学、金融和法律等基准上优于 GPT-6 Astra、Claude Fable 5.1 和 Claude Opus 5.5，并在 Embodied Reasoning（ERQA）基准上以纯推理得分 87%；Google DeepMind 称该模型解决了全部 12 个端到端模拟网络攻击场景（上一代为 5 个）。评测者 Ethan Mollick 称其较前代 Gemini 模型有明显跃升，但在复杂多智能体工作上仍有短板；评测者 indigo 则认为 Argon 让 Google 重新追上第一梯队但未超越对手，其配套应用 Antigravity 落后半年到一年。

OpenAI工程师涉在会议室装录音设备被捕

OpenAI称在办公室发现一个隐蔽录音装置，用自家模型分析设备及来源后锁定一名员工，将其解雇并移交FBI，FBI随后逮捕该员工。The Verge报道，被捕者是35岁工程师Abdulrahman Alfozan，设备于9月28日前后装在公司高管会议室电视的USB端口并用卫生纸遮盖，他被控使用或试图使用设备拦截口头通信。

后续报道称，该员工2025年7月起在OpenAI任职，10月9日被解雇，面临非法截获口头通信的联邦指控，最高可判5年监禁及25万美元罚款；设备约在安装两天后的9月30日被员工发现。美国司法部通报的起诉书还称，他通过妻子名下的聊天机器人账号获取搭建录音器、Wi-Fi连接和SD卡加密等提示。Ars Technica报道，FBI称10月5日安装摄像头后拍到Alfozan当天试图取回设备。

OpenAI表示目前没有迹象显示该员工不当访问或外泄模型权重、源代码或客户数据，也未说明装置本身录下了什么。有评论者将此事与一名前研究员关于中国在OpenAI和Anthropic安插间谍的说法相联系，该说法来自评论者，并非OpenAI或FBI的结论。

Anthropic 自研 Scion 替换 git 并分享经验

Anthropic 工程博客称，因 Claude 使代码合并量从 2026 年 5 月每天约 2,500 次增至 9 月超过 30,000 次，为人类规模设计的 Git 基础设施成为瓶颈，团队用五个月自研版本控制系统 Scion，并将整个 monorepo 从 Git 完全迁移，同时推出代码评审工具 Antique。

据 Simon Willison 等转述，其主分支历史近 100 GB，每天约 2,500 万次 CI 检出，若用 Git 将产生超过 600 PB 日流量；有转述称迁移后基础设施规模仅为原 Git 镜像的两百分之一。

Anthropic 表示，分享这些细节只是作为团队应对类似挑战的案例，不认为其方案适合所有情况，并明确 Scion 绝非 Git 的通用替代品。

Meta 发布首批前沿模型 Muse Wonder 系列

Meta 于 10 月 12 日发布 Muse Wonder 和 Muse Wonder Full 两款前沿智能体模型，这是其 Superintelligence Labs 成立一年多后的首批前沿模型。据 Artificial Analysis 实测，两款模型在 Intelligence Index v4.3 上分别得 52 和 56 分（最大推理量），较六周前 Muse Spark 1.3 的 48 分明显提升；Muse Wonder Full 在该指数上排名第二，距 Claude Opus 5.5 仅 2 分。

两款模型开放范围不同：Muse Wonder 可通过 Meta Model API、Muse Code 和 OpenRouter 使用，定价为每百万 token 输入 4 美元、缓存输入 0.20 美元、输出 20 美元；Muse Wonder Full 仅面向 Muse Code 订阅用户，不在 API 提供，按 token 定价尚未公布。Meta 称 Muse Wonder 将陆续接入 Muse 等其他产品，先向订阅用户推送。

Meta 称该系列在个人与专业智能体、记忆和编码基准上达到 SOTA，配备跨对话保留上下文的 Active Memory 和遇阻持续尝试的 Active Focus，并称在抵御对抗性指令、处理隐私信息方面做了专门训练。第三方评测者则给出不同侧重：有开发者称 Muse Wonder 一次找出其他 Agent 遗漏的代码漏洞，也有人汇总称 Muse Wonder Full 在 14 项公开基准中 8 项超过 Opus 5.5。Arena 后续公布 Muse Wonder (Max) 进入 Code Arena: WebDev 第 15 名（1651 分）、Text Arena 第 2 名（1513 分），并在基于超 5000 次真实智能体会话的 Agent Arena 中列第 12 名、净提升 +6.4%。

Epic 转向 AI 优先开发，Disney 游戏延期
